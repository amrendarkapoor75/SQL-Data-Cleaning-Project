# SQL Data Cleaning Project using MySQL

## 📌 Project Overview

This project demonstrates how to clean raw data using MySQL. The project includes duplicate detection, data standardization, date formatting, and SQL analysis queries.

## 🎯 Objectives

- Remove duplicate records
- Standardize inconsistent data
- Handle NULL values
- Convert date format
- Prepare clean data for analysis

- MySQL Workbench
- GitHub
